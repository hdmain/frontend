## How ordering works

1. Customer opens https://cp.alfahost.eu and creates an account (email verification).
2. Wallet top-up: BLIK (Stripe / PLN), Bitcoin, Litecoin.
3. Purchase deducts wallet balance; service appears in the panel.
4. Game servers: pick product → plan → engine (runtime) → deploy.
5. VPS NAT: pick plan → Linux image (Ubuntu/Debian) → root SSH on first mapped port (not 22).
6. VPS KVM DE/NL: pick plan → OS image (Linux or Windows Server) → public IPv4 + root/RDP.
7. One open support ticket at a time in the panel; Discord account can be linked for client role / ticket sync.
8. Website purchase buttons go to the panel; opening the panel alone is not an order.

## VPS NAT

- Category: vps
- Location: Warsaw, Poland
- Platform: Incus containers (LXC model — shared host kernel, hard resource caps)
- Network: shared public IPv4 of the host; dedicated block of **20 public ports** mapped 1:1
- SSH: listens on the **first port of the assigned block**, not port 22
- Anti-DDoS included
- Docs: https://docs.alfahost.eu/guides/nat-vps/

## FAQ (public)

**Is anti-DDoS free?**  
Yes. Every plan includes multi-layer protection from day one — no activation fee, no paid add-on.

**How fast can I deploy?**  
Most game images and VPS templates are ready within seconds after payment clears.

**Where are the servers?**  
Game servers and NAT VPS: Warsaw, Poland. KVM VPS: Frankfurt (DE) and the Netherlands. Dedicated: EU.

**NAT vs KVM?**  
NAT = shared host IP + fixed 20-port block, Incus/LXC, cheapest. KVM = own public IPv4, full OS including Windows Server options, higher isolation.
